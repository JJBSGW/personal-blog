# 写作模板:在后台「新建文章」中使用,或参考此结构写 Markdown

> 复制本模板内容到后台编辑器,替换各占位部分即可。

```markdown
# 文章标题(会作为 H1)

> 摘要:一两句话概括本文,将显示在首页列表。

## 背景 / 缘起

为什么写这篇文章?遇到了什么问题?(可用引用、列表等)

- 背景点 1
- 背景点 2

## 核心内容

### 小节一

正文内容。**加粗**、`行内代码`、[链接](https://example.com):

```ts
// 代码块:自动高亮并显示语言标签
const answer = 42;
console.log(answer);
```

### 小节二

支持表格(GFM):

| 列 A | 列 B |
| ---- | ---- |
| 1    | 2    |

> 温馨提示:引用块适合放注意事项。

## 踩坑记录(可选)

1. 坑一
2. 坑二

## 总结

- 要点 1
- 要点 2

---

*写于某年某月,深夜编码室。*
```

## 后台操作流程

1. 打开 `http://localhost:3000/admin` 登录
2. 「✏️ 新建文章」→ 粘贴以上模板
3. 填标题(建议 6~20 字)、摘要(1~2 句话)
4. 选状态:
   - **发布**:立即上线
   - **草稿** + 填「定时发布时间」:到点自动上线
5. 选分类、勾标签 → 保存
6. 到前台 `http://localhost:3000` 检查效果
